CG01-05 Player — iPhone / GitHub Pages 版
=========================================

這個版本已經把原本 80MB 以上的單一 HTML 拆開，所有單一檔案都低於 GitHub 網頁版 25MiB 的上傳限制。

請把這個資料夾中的內容「全部」上傳到同一個 GitHub repository 的根目錄：
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png / icon-512.png
- assets_cg01.js ~ assets_cg05.js
- backgrounds.js
- audio_*.js

之後在 repository：Settings → Pages → Deploy from a branch → main → /(root) → Save。

網站發佈後，用 iPhone Safari 打開 GitHub Pages 網址，再點分享 → 加入主畫面。
